# Бьянка — личный голосовой AI-ассистент

Бьянка понимает обычную речь, помнит контекст разговора и факты о тебе и умеет пользоваться функциями телефона. Все ответы формулирует модель: заготовленных фраз нет.

```
Телефон (Flutter)                       ПК
 ├─ распознавание речи / озвучка        ├─ Node.js-оркестратор (backend/)
 ├─ инструменты телефона  ◄──HTTP──►    │   ├─ цикл агента, системный промпт
 │   контакты, звонки, SMS, WhatsApp,   │   ├─ история диалога (data/sessions)
 │   карты, будильник, таймер, GPS      │   └─ долговременная память (data/memory.json)
 └─ UI: сфера, карточки действий        └─ Ollama (qwen3:8b)
```

Модель решает, *что* сделать. Сервер возвращает телефону вызовы инструментов, телефон их выполняет и присылает результат, после чего модель сама формулирует ответ.

## Запуск

### 1. Ollama
```powershell
ollama pull qwen3:8b      # слабая видеокарта (< 8 ГБ VRAM): qwen3:4b
```

### 2. Бэкенд
```powershell
cd backend
npm install
copy .env.example .env    # при необходимости поменяй модель/токен
npm start                 # или npm run dev (автоперезапуск)
```
Проверка без телефона:
```powershell
npm test                  # юнит-тесты цикла агента (Ollama не нужна)
npm run simulate          # реальные диалоги через Ollama с фейковым телефоном
npm run simulate -- "Позвони маме" "Что ты обо мне знаешь?"
```

### 3. Телефон
- **По USB:** `adb reverse tcp:3000 tcp:3000`, в приложении адрес `http://127.0.0.1:3000`, это значение по умолчанию.
- **По Wi‑Fi:** в настройках приложения (⚙️) укажи `http://<IP компьютера>:3000`. В `.env` обязательно задай `BIANCA_TOKEN` и впиши тот же токен в приложение.

```powershell
cd bianca_assistant
flutter run
```

## Что умеет

| Инструмент | Где выполняется |
|---|---|
| `remember` / `forget`: долговременная память | сервер |
| `find_contact`: нечёткий поиск с учётом падежей («маме» → «Мама») | телефон |
| `make_call` | телефон, после озвучки ответа |
| `send_sms`, `send_whatsapp`: открывает с готовым текстом, только после «да» | телефон, после озвучки |
| `get_location`: координаты и адрес | телефон |
| `navigate_to`, `search_nearby` | телефон, после озвучки |
| `set_alarm`, `set_timer` | телефон |

Новый инструмент добавляется в два места: схема в [`backend/src/tools.js`](backend/src/tools.js), реализация в [`DeviceTools`](bianca_assistant/lib/services/device_tools.dart).

## API

| Метод | Назначение |
|---|---|
| `POST /api/turn` | `{sessionId, text?, toolResults?, context?}` → `{type: "reply", text}` или `{type: "tool_calls", calls}` |
| `GET /api/health` | состояние Ollama и наличие модели |
| `DELETE /api/session/:id` | забыть текущий диалог |
| `GET /api/memory`, `DELETE /api/memory/:id` | просмотр и удаление долговременных фактов |
